3 Connect MetaMask
🦊 MetaMask Signing: MetaMask is a browser wallet that makes signing transactions easy and secure. You'll see a popup to review and approve the transaction.
⚠️ Important Note: MetaMask signs and broadcasts transactions together in one step. Your transaction will be sent to the blockchain immediately after approval.
Don't have MetaMask? Download it here (it's a free browser extension)
🔑 Need to sign with a Private Key?
For security reasons, private key signing is not available in the hosted version.
Download the Private Key version to sign transactions locally using your private key.
4 Sign & Broadcast Transaction
ℹ️ What happens: MetaMask will prompt you to review and approve the transaction. Once approved, your transaction will be signed and broadcast to the blockchain in one step.
After clicking, MetaMask will open a popup where you can review the transaction details before approving.

          What is this tool?

              A secure blockchain transaction signing tool that works entirely in your browser. 
            

            
Use it for:

            
    
              
  • Token Actions V2 API integration
    • 
              
  • General blockchain transactions
    • 
              
  • Testing on testnets

          Why sign transactions?
          ▼
        

        

          

            

              Your digital signature proves you authorized the transaction.
            

            
    
              
  • ✅ Proves wallet ownership
    • 
              
  • ✅ Cannot be forged
    • 
              
  • ✅ Keeps assets secure
    • 
            

          

        

      


      
      

        

          How does it work?
          ▼
        

        

          

            
3 simple steps:

            
    
              
  • 📥 Get transaction details
    • 
              
  • ✍️ Sign with private key or MetaMask
    • 
              
  • 📤 Broadcast or send to API
    • 
            

            

              💡 For Token Actions V2:

              
                • Signing only → /payloads endpoint

                • Broadcast → /transactions endpoint
              
            

          

        

      


      
      

        

          Blockchain terms
          ▼
        

        

          

            

              Wallet: Your digital account
            

            

              Transaction: Any blockchain action
            

            

              Signing: Approving with your private key
            

            

              Broadcasting: Sending to blockchain
            

            

              RPC URL: Network connection point
            

            

              Chain ID: Network identifier number
            

            

              Gas: Transaction fee
            

            

              Transaction Hash: Unique transaction ID
